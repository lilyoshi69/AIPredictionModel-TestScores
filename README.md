# AIPredictionModel-TestScores
Can a computer predict a test score using study time and sleep? This project uses a simple AI model to analyze these factors and estimate student performance.

## Problem
Many students wonder what factors affect their test scores. This project explores whether a computer can predict a test score based on how long a student studies and how much sleep they get. Understanding this can help students see patterns between habits and performance.

## Solution
I created a simple AI model that looks at study time and sleep hours as inputs and predicts a test score as the output. The model learns from example data and finds relationships between these factors to make predictions for new inputs.

## Tools
- Python  
- Pandas  
- Scikit-learn  
- Google Sheets

## Results – Output Screenshot
The model was able to make reasonable predictions based on the input data. As study time and sleep increased, the predicted test score generally increased as well. This shows the model learned a basic relationship between good study habits, rest, and performance.
